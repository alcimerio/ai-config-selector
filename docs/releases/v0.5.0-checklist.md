## Validation and trust limits

The native macOS 26 Apple Silicon release gate passed its normal, race, installed-artifact, containment, terminal, lifecycle, recovery, and shared Devin/Codex checks. Its locked CI targets were Codex CLI/code-mode host 0.149.1 and Devin 3000.10.21, both `darwin/arm64`. The Codex fixture used synthetic authentication and a loopback simulated API; it did not use a real account or hosted inference. The parallel macOS validation run also passed. Linux compilation is a non-blocking portability observation, not release evidence.

SHA-256 identifies bytes against a trusted digest, and the verified GitHub attestation supplies origin evidence for its two subjects. Neither establishes Apple Developer ID signing, notarization, malware review, or Gatekeeper approval. Do not remove quarantine, disable Gatekeeper, ad-hoc sign the binary, or weaken Seatbelt as a workaround.

The [README bootstrap](../../README.md#install) uses the published v0.5.0 installer in a new empty user-owned directory for v0.4.0 users, whose binary has no `acs update`. Binary rollback does not downgrade Profile, Session, history, transaction, or named-authentication state. The [candidate migration guide](../release-migration-guide.md) is for separately identified development artifacts; the [manual recovery guide](../manual-upgrade-recovery.md) covers release-pinned maintenance. The expired PR #118 candidate in the [historical handoff](../current-candidate-handoff.md) remains historical.

The immutable Release body links to guide revisions pinned at the v0.5.0 tag;
those revisions retain pre-publication wording. For current procedures use the
