# ACS v0.2.0

ACS v0.2.0 adds downloadable, release-pinned binaries for macOS 26 and Ubuntu
24.04 LTS while preserving the v0.1.0 Profile and launch contracts.

## Installation

Download the release-specific installer, inspect it, and execute the local
file. Do not pipe the download into a shell.

```sh
release_version=v0.2.0
release_url="https://github.com/alcimerio/ai-config-selector/releases/download/$release_version"
curl --fail --location --proto '=https' --tlsv1.2 \
  --output install.sh "$release_url/install.sh"
less install.sh
sh ./install.sh
acs version
```

The version command must print exactly `acs v0.2.0`. The default destination
is `~/.local/bin`; pass `--bin-dir` with a user-writable absolute directory to
choose another destination. The installer prints PATH guidance when needed but
does not edit shell files, invoke `sudo`, or replace an existing binary.

## Supported Platforms and Release Targets

- macOS 26: `darwin/arm64` and `darwin/amd64`
- Ubuntu 24.04 LTS: `linux/amd64` and `linux/arm64`

Windows, WSL, other Linux distributions, and other target pairs are not
supported. The Release Artifact Set contains exactly four target archives,
`SHA256SUMS`, and the release-specific `install.sh`.

## Verification

The installer independently verifies the selected archive against
`SHA256SUMS`. README.md documents manual SHA-256 commands and
`gh attestation verify` for the four archives and checksum manifest. GitHub
build provenance identifies the repository and workflow that produced the
attested bytes; it does not establish source safety, malware absence, or an
Apple developer identity.

## Compatibility

v0.2.0 reads existing v0.1.0 Profiles without migration and preserves Profile
envelopes, category schemas, commands, accepted messages, permissions, atomic
persistence, Profile Builder behavior, Devin Adapter behavior, signal and exit
handling, Session isolation and cleanup, and ACS Home at `~/.acs`. Local
checkout builds remain development builds and report `acs devel`; downloadable
release binaries are the Supported Install Path.

## Relevant changes

- Added Linux runtime support without creating a platform-specific product
  mode.
- Added four reproducible CGO-disabled release archives and a pinned installer.
- Added exact promoted-artifact validation on all four native targets.
- Added sanitized authenticated Devin evidence for macOS arm64 and Ubuntu
  amd64 release gates.
- Added build-once provenance attestation and forward-only immutable Release
  publication.

## Known limitations

The macOS binaries are unsigned and unnotarized. Gatekeeper may warn about or
block them because they have no Apple Developer ID signature or notarization
ticket. SHA-256 and GitHub attestations do not provide signing, notarization,
Apple malware review, or Gatekeeper trust, and users should not weaken host
security on the assumption that they do.

ACS supports only Devin and Skills, does not filter repository-local Skills,
and provides configuration isolation rather than an OS sandbox. It has no
package-manager distribution, automatic update, self-update command, or
uninstaller.
