# ACS v0.4.0

ACS v0.4.0 adds a credential-free interactive sandbox shell and narrows the
supported release surface to macOS 26.

## Sandbox shell

Use a named Profile without starting an AI CLI:

```sh
acs sandbox --profile PROFILE
```

ACS creates an ephemeral Session, materializes the selected Skills, and starts
the fixed system `/bin/zsh -f` inside Seatbelt. The shell does not consult
`$SHELL`, load user startup files, invoke Devin, copy a Devin credential, or run
Devin preflights.

The shell receives the invoking terminal and preserves input/output, resize,
signals, interactive line editing, and ordinary exit status. The minimal
system-read policy includes the macOS terminfo database required to redraw
Backspace correctly without granting the rest of `/usr/share`. Its descendants
share the Seatbelt policy and must settle before the Session can be removed.
Cleanup that cannot prove settlement remains quarantined.

Inspect the plan without creating a Session:

```sh
acs sandbox --profile PROFILE --dry-run
```

The dry run reports materialized Profile content and native backend readiness.
It excludes repository-local Skill inheritance that belongs specifically to
the Devin adapter.

## Shared Session boundary

Session creation and Profile materialization are now target-independent. Devin
adds its allowlisted credential and performs Skill/authentication verification
only after the generic Session exists. The sandbox shell uses the same selected
Skills and lifecycle without receiving those Devin-specific capabilities.

## macOS-only support

The supported v0.4.0 matrix is:

| OS | Target | Backend |
| --- | --- | --- |
| macOS 26 | `darwin/arm64` | verified system Seatbelt |
| macOS 26 | `darwin/amd64` | verified system Seatbelt |

v0.3.3 is the final release with Linux support. Bubblewrap source remains in the
repository without v0.4.0 Linux binaries, installer support, native gates, or a
support commitment. A non-blocking Linux compile observation may expose obvious
portability breakage but is not release evidence.

## Isolation boundary

The Seatbelt policy permits the workspace, leased Session, required macOS
runtime, terminal, and outbound IP/DNS. It denies tested unrelated host paths,
external writes, symlink escapes, arbitrary environment values and descriptors,
and unrelated Unix sockets. ACS is not an egress firewall, and there is no
unsandboxed fallback.

Release evidence installs the exact candidate bytes on macOS 26 arm64 and Intel
and exercises Skills, credential absence, filesystem allow/deny behavior,
terminal lifecycle, descendants, and cleanup before attestation and immutable
publication.

## Compatibility

Existing Profile files remain compatible. The Devin commands are unchanged.
The new public grammar is:

```text
acs sandbox --profile <name> [--dry-run]
```

Arbitrary command execution, shell selection, network filtering, additional
adapters, and additional Profile categories remain out of scope for v0.4.0.
