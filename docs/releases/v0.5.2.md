# ACS v0.5.2

ACS v0.5.2 improves installation guidance. The supported runtime remains
macOS 26 on Apple Silicon (`darwin/arm64`) with Seatbelt.

## Installation

- Reject unsupported or undetectable macOS versions before downloading release
  assets. The installer accepts macOS 26 and still checks the OS and architecture.
- Suggest `acs update` when the installation destination already exists.
  The installer preserves the existing entry and refuses to overwrite it.
- Simplify the README installation command and keep installer inspection as an
  optional procedure.

## Documentation

Consolidate user procedures, reference contracts, and contributor documentation.
Current guides use stable release links and operator-supplied version and digest
inputs instead of tracking the latest release number.

## Upgrade and compatibility

Existing installations in the supported direct, user-owned regular-file layout
can use `acs update --check` and then `acs update v0.5.2`. This patch does not
change Profile, exchange, or Session formats or add a stored-data migration.
For other layouts, follow the
[manual upgrade and recovery guide](https://github.com/alcimerio/ai-config-selector/blob/v0.5.2/docs/guides/manual-upgrade-recovery.md).

ACS remains unsigned and unnotarized. The installer does not require `sudo`, edit
shell startup files, or change Gatekeeper settings.
