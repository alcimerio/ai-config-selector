# ACS v0.3.3

v0.3.3 is the corrected process-isolation candidate for the existing Devin
and Skills Profile model. Existing Profile files and selections remain
compatible, while every launch still requires a certified host and a ready
native backend. There is no unsandboxed fallback.

## Relationship to unpublished candidates

The `v0.3.0`, `v0.3.1`, and `v0.3.2` tags were pushed but never published as
GitHub Releases because required native gates failed. They remain immutable,
unpublished, and non-authoritative. If publication succeeds, v0.3.3 is the
first published process-isolation release and supersedes all three candidates.

## Patch correction

The v0.3.2 native macOS gate exposed a process-table race while a descendant
was becoming a zombie. The supervisor could enumerate the process as still
addressable and then fail to reread its identity immediately before cleanup,
causing exit 125 and withholding publication.

v0.3.3 treats that unreadable identity as an unstable snapshot. It sends no
signal without successful identity revalidation and retries a fresh snapshot
only within the existing bounded settlement deadline. Persistent ambiguity
still fails closed. A deterministic unit regression and concurrent native
stress on both supported macOS architectures cover the transition.

## Installation

After the immutable GitHub Release is public, download and inspect the
release-specific installer. Do not pipe network content into a shell.

```sh
release_version=v0.3.3
release_url="https://github.com/alcimerio/ai-config-selector/releases/download/$release_version"
curl --fail --location --proto '=https' --tlsv1.2 \
  --output install.sh "$release_url/install.sh"
less install.sh
sh ./install.sh
"$HOME/.local/bin/acs" version
```

The final command must print `acs v0.3.3`. The installer binds the selected
archive to `SHA256SUMS`, validates its version and structure, and does not use
`sudo`, replace an existing `acs`, or edit shell startup files.

## Supported release matrix

| Host | Download target | Required backend |
| --- | --- | --- |
| macOS 26 | `darwin/arm64` | verified system Seatbelt |
| macOS 26 | `darwin/amd64` | verified system Seatbelt |
| Ubuntu 24.04 LTS | `linux/amd64` | verified signed-system Bubblewrap |
| Ubuntu 24.04 LTS | `linux/arm64` | verified signed-system Bubblewrap |

Windows, WSL, other Linux distributions, and other OS/architecture pairs are
not supported by this release. A source build reports `acs devel` and is not
release evidence.

## Protection and evidence contract

Configuration isolation remains owned by the synthetic Session; process
isolation remains owned by the native Process Sandbox. The sandbox exposes the
workspace, leased Session, and Session temporary directory as writable,
provides only required system/runtime inputs, rebuilds the environment, and
supervises descendants through authenticated cleanup. Unsupported or unsafe
hosts, backends, paths, environments, descriptors, policies, and preflight
state stop before Devin starts.

Every public protection claim is limited to the four-target native evidence
contract in [issue #62](https://github.com/alcimerio/ai-config-selector/issues/62),
the [native candidate tests](../../acceptance/promoted_artifact_native_test.go),
the [candidate lifecycle tests](../../acceptance/promoted_artifact_test.go),
and the [release workflow](../../.github/workflows/release.yml). The optional
authenticated smoke never replaces this credential-free gate.

## Limitations

ACS is not an egress firewall; outbound IP remains available. Repository-local
Skills remain controlled by Devin. Signed-system Bubblewrap verification does
not protect against a compromised administrator. macOS binaries are unsigned
and unnotarized. The broad Seatbelt prototype remains feasibility history and
is not a production policy claim.

See the [architecture](../architecture.md#v033-native-evidence-map),
[contributor release procedure](../../CONTRIBUTING.md), and
[README limitations](../../README.md#known-limitations) for the maintained
contract.
