# ACS v0.4.0 release checklist

This checklist separates source readiness from the tag-triggered immutable
release. Never move or delete a release tag after it is pushed.

## Source and contract

- [ ] `acs sandbox --profile NAME` launches exactly `/bin/zsh -f`.
- [ ] `--dry-run` resolves the Profile without creating a Session or target.
- [ ] Selected Skills are materialized into the sandbox-shell Session.
- [ ] No Devin credential, executable, authentication probe, or Skill preflight
      is used by the sandbox shell.
- [ ] Workspace/Session access, denied host paths, clean environment, terminal
      line editing, signals, resize, exit status, descendants, cleanup, and
      quarantine are covered by automated tests.
- [ ] Existing Devin and Profile compatibility suites pass.
- [ ] Runtime validation rejects unsupported platforms before Session creation.

## Artifact contract

- [ ] `.goreleaser.yaml` builds only `darwin/arm64` and `darwin/amd64`.
- [ ] The candidate contains exactly two archives, `SHA256SUMS`, and `install.sh`.
- [ ] The installer rejects non-macOS hosts before download.
- [ ] Promoted and release native matrices contain only macOS 26 arm64 and Intel.
- [ ] Linux has no native gate and only a non-blocking compile observation.

## Pre-tag evidence

- [ ] The release-preparation PR is merged to protected `main`.
- [ ] Formatting, vet, module verification, normal tests, and race tests pass.
- [ ] Promoted artifact validation passes on `darwin/arm64`.
- [ ] Promoted artifact validation passes on `darwin/amd64`.
- [ ] The exact candidate is verified locally with:

  ```sh
  scripts/release-candidate.sh v0.4.0
  ```

- [ ] Release notes and this checklist are committed at the tag source.
- [ ] Optional authenticated Devin smoke is recorded only as supplemental
      pass/fail evidence, with no sensitive output.

## Tag and immutable publication

- [ ] Create the annotated protected tag with:

  ```sh
  scripts/prepare-release-tag.sh v0.4.0
  ```

- [ ] Push only `refs/tags/v0.4.0`.
- [ ] Tag identity and protected-main ancestry pass.
- [ ] The candidate is built once and reused by both native jobs.
- [ ] Native `darwin/arm64` passes normal, race, and black-box acceptance.
- [ ] Native `darwin/amd64` passes normal, race, and black-box acceptance.
- [ ] Both archives and `SHA256SUMS` receive GitHub attestations.
- [ ] The protected `release` environment is approved.
- [ ] The GitHub Release becomes immutable with exactly four assets:
  - `acs_0.4.0_darwin_arm64.tar.gz`
  - `acs_0.4.0_darwin_amd64.tar.gz`
  - `SHA256SUMS`
  - `install.sh`

## Post-publication

- [ ] Verify the public installer independently on macOS arm64.
- [ ] Verify the public installer independently on macOS Intel.
- [ ] Verify GitHub attestations for both archives and `SHA256SUMS`.
- [ ] Update the README's latest-published-release sentence in a follow-up PR.
- [ ] Record public workflow, release, and attestation links here without
      credentials, target output, Session contents, private paths, environment
      values, generated policy, or terminal control characters.
