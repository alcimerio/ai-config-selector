# ACS v0.4.0 release evidence

The v0.4.0 publication is complete. This record captures its source-readiness,
tag-triggered, and public-release evidence without claiming that every item in
the original pre-publication checklist was performed. Only public, sanitized
facts are recorded here; credentials, private paths, Session contents,
environment values, generated policies, and raw terminal output are excluded.

Never move, delete, or reuse a release tag after it is pushed.

## Released contract

v0.4.0 is the first macOS-only ACS release. Its release contract includes:

- `acs sandbox --profile NAME` launches exactly `/bin/zsh -f` inside the
  required fail-closed Seatbelt sandbox;
- dry-run resolves the Profile without creating a Session or target;
- the sandbox shell materializes selected Skills without using a Devin
  credential, executable, authentication probe, or Skill preflight;
- automated coverage includes workspace and Session access, denied host paths,
  clean environment, terminal line editing, signals, resize, exit status,
  descendants, cleanup, and quarantine;
- existing Devin and Profile compatibility suites remain required; and
- runtime validation rejects unsupported platforms before Session creation.

The candidate and installer contain only macOS `darwin/arm64` and
`darwin/amd64` artifacts. Linux has no binary, native gate, installer path, or
support commitment in this release; its retained source receives only a
non-blocking portability compile observation.

## Pre-tag evidence

The release-preparation work was merged to protected `main`. Formatting, vet,
module verification, normal tests, race tests, promoted-artifact validation on
both supported architectures, and the exact local candidate command passed:

```sh
scripts/release-candidate.sh v0.4.0
```

Release notes and the pre-publication checklist were committed at the tag
source. Review confirmed the candidate contained exactly two archives,
`SHA256SUMS`, and `install.sh`; the installer rejected non-macOS hosts before
download; and both promoted and release native matrices contained only macOS
26 arm64 and Intel.
